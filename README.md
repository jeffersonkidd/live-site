# JeffersonKidd.com 

This repository contains the source code for jeffersonkidd.com, reflecting the live website's current state

## Project Overview:

Jeffersonkidd.com serves as the personal website of Jefferson Kidd, providing visitors with contact information and links to social media profiles.

## Features:

- Contact Information: Provides an email contact option for visitors.  

- Social Media Links: Includes links to various social media platforms.  

- Technologies Used:  
  - HTML5
  - CSS3
  - JavaScript
